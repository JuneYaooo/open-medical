# 企业微信患者触达

适用：已连接企业微信，工具列表里有 `wecom_*` 和 `care_*` 工具。没有这些工具时，告诉医生先在「设置 → 患者随访」连接企业微信，不要假装能发送。

## 通用规则

- 所有会发给患者或客户群的操作都只生成待确认提案。告诉医生到「待确认」面板核对，不说“已发送”。
- 发给患者的文字：称呼 + 一件事 + 需要对方做什么 + 有问题怎么联系，三到五句话。不写诊断结论、处方或剂量调整；涉及病情变化时，请患者来门诊或复诊。
- 群发只发科普和通知，不出现任何个人病情、姓名或检查结果。
- 署名和口吻按医生在「学习与记忆」里确认过的习惯；没有就用“X 医生诊室”。

## 1. 新客户关联到患者档案

1. `wecom_customers` 查新加的客户和系统推荐的匹配患者。
2. 推荐匹配只是线索：向医生说明依据（备注名、手机号后四位、来源等），由医生确认是本人还是家属。
3. `wecom_bind_propose` 生成关联提案。关联后，这位患者的随访问卷和提醒才能通过企业微信发送。

## 2. 复诊、检查提醒

- 先用 `followups_overview`、`care_overview` 或复诊名单找到该提醒的患者；一次处理多位时，逐位生成提案并汇总给医生。
- 用 `care_send_propose` 生成单条消息。示例：
  > 王阿姨您好，我是李医生诊室。您上次约的复查时间是本周五（11 月 7 日）上午，记得空腹抽血，带上近一周的血压记录。时间不方便请直接回复，我们帮您改约。
- 需要按节奏反复提醒、并自动收集回复的，用 `care_campaign_propose` 建自动随访（每步可带简短问题）。

## 3. 随访话术与问卷

- 要结构化回收、自动计分的，转用「快速做随访问卷」（questionnaire-builder）。问卷到期后，医生在患者随访页选择“企业微信客户联系”或“微信客服”下发；患者在企业微信里按题号回复，系统自动计分。
- 只是问候和简单确认的，用 `care_send_propose`。
- 患者回复后，用 `care_inbox`、`care_patient_thread` 查看，`care_reply_draft` 起草回复，只存草稿。出现红旗症状时，系统会固定提醒，按提示建议患者立即就医。

## 4. 客户群科普

1. `wecom_groups` 找到目标群（如“高血压管理群”）。
2. 内容从知识库「患教素材」或医生已审核的资料里取，用 `guideline_search` 检索，标注出处；没有依据的部分不写。
3. 写成一条 300 字以内的群消息：一个主题、两到三个要点、一句“个人情况请私信或来门诊咨询”。
4. `wecom_group_message_propose` 生成群发提案。医生确认后，由群主在企业微信里点发送。

## 5. 每周盘点（医生说“看看这周的患者”时）

汇总：本周到期的随访和问卷回收情况、未回复的患者、触发预警的患者、新加未关联的客户。对每一类给出下一步建议，并给出对应的提案或待办入口。
