# 快速做随访问卷

目标：医生说一句话，几分钟内拿到一份患者能在手机上直接回复、系统能自动计分和预警的问卷。

## 1. 弄清三件事，能推断就不问

- **给谁、为什么**：病种或场景（高血压月度自测、术后 1 周、糖尿病低血糖筛查、满意度回访……）。
- **用一次还是反复用**：只给眼前这位患者，还是存成模板以后给一类患者用。
- **什么情况要提醒医生**：哪些答案或数值需要进今日待办。

医生没说的用默认值，在预览时一并说明，不要连续追问。一次最多问一个问题。

## 2. 起草问卷

- 题目控制在 3–8 题，患者在手机上逐题回复，越短回收率越高。
- 优先用 `single`（单选）和 `number`（数值），能自动解析；`text` 简答只放最后一题，用于“还有什么想告诉医生”。
- 选项 2–5 个，文字短（“经常 / 偶尔 / 没有”），不同题的选项不要都一样，患者回复时不易混淆。
- 关键题设为必答（`required: true`）。
- 数值题写清单位和时间点（“最近一周晨起自测收缩压平均值”，单位 mmHg），并设合理的 `min`/`max`。
- 预警：
  - 单题危险值用 `alertIf`（如收缩压 >180、空腹血糖 <3.9）。阈值取常见临床共识中偏保守的值，并在预览里告诉医生，由医生调整。
  - 多题综合风险用选项分值 + `scoring.alert`（总分 ≥ 阈值）。阈值必须落在可能得分范围内。
  - 预警说明写“建议尽快复核……”，不写诊断结论。
- 患者看到的文字用大白话，不出现诊断、处方或剂量调整建议。
- 标准量表（PHQ-9、GAD-7 等）可以用公开版本的原题；有版权限制的量表不要全文复制，改为说明“建议使用院内授权版本”。

## 3. 预览，给医生看

调用 `questionnaire_preview`。把下面三项给医生：

1. `patientText`：患者在企业微信/微信里收到的原样文字；
2. 预警规则：哪些答案会提醒医生；
3. `notes` 里的提醒（阈值不可能触发、题太多、没有必答题等），并说明你用了哪些默认值。

医生要改就改完再预览一次。

## 4. 保存

按医生的意图选择，都会生成待确认提案，告诉医生到「待确认」面板核对，不要说“已保存”或“已发送”：

| 场景 | 工具 |
| --- | --- |
| 只给当前这位患者，到某天发 | `followup_create_propose`，带上 `questionnaire`，`firstDueAt` 写发送日期 |
| 存成模板，以后给一类患者用 | `followup_plan_propose`，问卷挂在对应节点上（如第 30 天、第 90 天） |
| 已有模板，给患者套用 | 先 `followup_plans_list` 找模板，再 `followup_plan_apply_propose` |

## 5. 下发与回收（已连接企业微信或微信时）

- 随访到期后，系统生成问卷，今日待办会提示“问卷待下发”。医生在患者随访页点“下发问卷”，选择渠道：
  - 企业微信客户联系：生成群发任务，成员在企业微信里确认后才真正发出；
  - 微信客服：只有患者 48 小时内发过消息时可用；
  - 企微机器人、微信（已验证）、手动复制发送。
- 患者按题号回复（如“1. 偶尔”）即可。系统在本机解析、计分，触发预警时进入今日待办。回收和计分不经过模型，也不依赖是否开启消息自动分诊。
- 没有连接患者渠道时，问卷仍然可以保存，也可以“手动复制发送”给患者；收到回复或电话随访后，在患者随访页“代填”。要如实告诉医生这一点，不要暗示能自动发送。
