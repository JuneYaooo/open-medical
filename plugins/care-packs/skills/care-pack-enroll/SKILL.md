# 专病管理包入组

专病管理包 = 一个病种的随访计划 + 随访问卷 + 检验监测阈值 + 患教素材。医生装好包后，一句话就能把患者纳入管理。

## 步骤

1. **确认患者和病种**：当前患者用 `read_patient_brief` 看诊断。诊断里没有该病种时，先向医生确认，不要自行判断。
2. **选包**：`care_pack_list` 查看可用的包。按诊断匹配；同时有多个病种（如高血压合并糖尿病）时，可以分别应用，并提醒医生两个包的随访节点会叠加，必要时用「快速做随访问卷」合并成一份。
3. **开始日期**：默认今天或本次就诊日期，医生另有说明的按医生说的。
4. **生成提案**：`care_pack_apply_propose`。向医生简要说明会发生什么：
   - 哪几天会有随访提醒，哪些节点带问卷；
   - 新增哪些检验监测（如血钾 >5.5、糖化血红蛋白 >9%）；已有同项目同方向的监测不会重复添加。
   提案确认前不要说“已纳入管理”。
5. **配合企业微信（已连接时）**：
   - 患者还没关联企业微信客户的，提醒医生先关联（见「企业微信患者触达」），否则问卷到期时只能电话随访、手动代填；
   - 可以从知识库「患教素材」里挑选包内对应的科普，用 `care_send_propose` 发给患者；患教素材需要医生在设置里先安装专病包才会导入。

## 边界

- 包里的阈值和随访节奏是通用起点，医生可以按患者情况调整；调整单个患者的计划，用随访工具修改，不要改包本身。
- 包的内容不替代医生判断，问卷预警只是提醒医生复核。
