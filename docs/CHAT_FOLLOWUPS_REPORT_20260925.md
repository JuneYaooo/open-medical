# 微信与企业微信聊天随访交付报告

日期：2026-09-25

## 已实现

- 设置页分别配置微信桌面和企业微信存档，保存、测试、运行状态独立展示；连接凭据进入现有凭据保险库。
- 随访页与患者沟通页关联患者本人或家属会话。企微群聊或共享家属会话涉及多位患者时，消息先人工分配，避免自动串入另一位患者档案。
- Mac 微信使用本机窗口控制和 Apple Vision。首次关联校准标题与消息区域，随后核验标题、窗口比例和读取前后状态；保留裁剪证据。身份不明确或识别失败时停止。
- 企微提供独立、只读的 Python 采集器源码，连接官方会话存档 C SDK。包含访问鉴权、限定成员及会话范围、RSA 解密、字符串 uint64 游标、分页与错误处理。
- 企微新增关联重新扫描可用存档并按来源去重；已成功页面与游标事务提交，中途失败可以续读。
- 草稿保留原文与来源，支持授权模型整理、人工修改、真实联系时间确认和幂等归档。撤回消息标记来源变化，人工编辑不会被晚到的模型结果覆盖。
- 自动同步最长授权未来 24 小时；可另外授权当前模型自动整理新增草稿，更换模型后停止自动整理。应用退出或停止操作会取消任务。默认不启用自动同步或模型外发。
- 草稿记录分页；解除关联保留已有证据与记录。旧的整窗截图读取与盲选首结果发送接口已停用。

## 选型依据

优先审查了 [wechat-desktop-automation](https://github.com/JuneYaooo/wechat-desktop-automation)，同时比较 [WeWorkFinanceSDK](https://github.com/NICEXAI/WeWorkFinanceSDK)、[WeworkMsg](https://github.com/Hanson/WeworkMsg)、[go-wecom](https://github.com/wenerme/go-wecom) 与 [WeworkChatSDK](https://github.com/chinayin/WeworkChatSDK)。

参考项目的可见桌面核验方式适合个人微信；企微采用会话存档接口，二者不混用凭据或消息身份。Mac 适配与 Python 采集器为本项目独立实现，未复制分发参考仓库脚本或下载第三方 SDK 二进制。详见[调研记录](research/followup-chat-integration.md)。

## 真实能力边界与部署条件

1. 尚未完成指定真实微信测试会话及真实企业存档账号联调。没有真实企业凭据、官方 SDK 动态库和授权存档，不能宣称企微已接通。
2. 个人微信只读取可见区域，不抓取完整数据库或自动翻阅全部历史。OCR 的相邻画面去重是保守估计，无法保证消息完整性；无法确认连续性时提示可能重复或遗漏。
3. 微信账号标识由用户核验，窗口标题不是稳定的联系人 ID。换账号、改备注或改变窗口布局后必须重新关联；发送者与消息时间无法可靠识别时保持待核验。
4. 应用内微信适配目前为 macOS。企微采集器需在官方 SDK 支持的环境部署，安装包只附源码与说明，不附企业密钥或 SDK。
5. 企微语音、图片等只保留消息类型与来源，不自动下载或理解媒体。过期、未授权或从未存档的历史无法补齐。
6. 自动模型整理每轮最多 3 份新草稿；失败项留待人工重试。模型结果不自动写成已完成随访，归档由医生核对。

使用入口与部署步骤见[聊天随访说明](chat-followups.md)及[企微采集器说明](../integrations/wecom-archive/README.md)。

## 配置体验修订

首次接入改为分步流程：微信先检查客户端与权限，再由用户核对微信号；企业服务的技术字段放入管理员配置，验证成功才启用。验证失败保留配置和密钥，展示失败状态并允许修正重试。接通后提供直达聊天随访的入口，自动同步设置在连接通过后出现。

企微手填会话与发送者 ID 移入高级选项。微信预览会尝试根据唯一、高置信度的标题匹配给出标题区域建议；消息区域仍由用户选择，避免通过猜测扩大采集范围。标题定位不替代账号、患者关系和画面的人工核验。

本次修订通过 27 项专项测试（含 4 条真实浏览器操作流程）、ESLint 和生产构建。合成采集器与模型用于隔离测试，真实账号联调边界不变。最新日志：`output/chat-setup-final-tests.log`、`output/chat-setup-lint.log`、`output/chat-setup-build.log`。

修订版已重建、替换并启动桌面应用，实机核对微信首次接入页、权限检查反馈、企微默认页与管理员配置展开。实机检查返回桌面组件缺少辅助功能权限，因此尚未启用微信连接或读取聊天。安装指纹一致性证据见 `output/chat-setup-installed-integrity.json`，安装包验证见 `output/chat-setup-desktop-verification.json`；旧程序与本次重复候选包已清理。
