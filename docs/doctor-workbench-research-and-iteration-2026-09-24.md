# 医生工作台：产品调研与本地迭代

调研日期：2026-09-24。对象：以本地患者资料为基础、由医生发起任务的医疗工作台。本文区分公开产品能力、由公开资料推导的设计建议，以及实际实现和验收结果。没有开展医生访谈，不能把设计判断当作已验证的用户研究。

## 一、产品目标与取舍

医生进入软件通常是为了完成当前的一件事：看资料、回答一个临床问题、安排复查、核对试验条件、查指南。首页应提供直接提问和上传材料；患者页面按临床内容分区；执行日志、工具调用、哈希、历史任务等放到次级入口。普通提问直接回答，文献、相似病例、计算器、辅助诊断使用适合阅读的结果界面。保存结果和人工核对是独立动作，不能因未复核而让模型无限运行。

本轮保留通用任务、项目、工具的独立入口；医疗导航调整为患者、随访、临床试验、知识库。统计计算仍作为工具可用，不占据主要医疗业务入口。

## 三、随访：详细可用建议

### 1. 随访工作的最小闭环

1. 医生确定随访目的、时间和要核对的事项。
2. 到期生成待办；软件运行与否、通信通道是否连接，应明确显示。
3. 医生登记实际联系结果：已联系、未联系上、暂不接受。
4. 已联系时可记录症状近况、实际用药、检查结果、下一步安排。
5. 需要再次联系时安排单次提醒；原有周期计划保持独立。
6. 需要解释结果或整理问题时，携带本次记录及补充记录打开患者任务草稿。
7. 记录有误时追加更正，不覆盖旧记录。

依据：[AHRQ RED 随访电话工具](https://www.ahrq.gov/patient-safety/settings/hospital/red/toolkit/redtool5.html)关注健康状态、药物、预约、家庭支持和问题发生后的应对；[RED 工具包](https://www.ahrq.gov/patient-safety/settings/hospital/red/toolkit/index.html)还强调待回报结果和出院计划衔接。其特定出院流程中的时间建议不能直接套用为所有慢病或肿瘤患者的统一间隔。

### 2. 主要界面

- 默认显示“随访待办”，按患者姓名或主题查找；记录页可按联系结果筛选。
- “记录一次联系”允许登记没有预先排程的主动联系。
- 临床要点默认折叠、均为可选；短随访可以只写一段记录。
- “未联系上”时不显示“已核实症状”等选项，避免记录语义矛盾。
- 计划与模板放独立页签，默认不展示整页模板目录。
- 应用模板时展示并允许调整当前患者的节点、时间和核对事项。
- 接诊上下文需要包含已保存的临床反馈、日期和来源，而不只是“随访完成”的状态。

### 3. 按疾病调整，而不是硬编码统一日期

| 场景 | 适合放进模板的核对主题 | 不能自动推断 |
| --- | --- | --- |
| 出院后过渡期 | 患者是否理解计划、药品实际取得与使用、复诊和待回报检查 | 未接电话不能视作病情稳定 |
| 肿瘤治疗随访 | 本次治疗阶段、近期症状、既有检查安排、患者关注的问题 | 不能仅凭诊断名生成统一影像/肿瘤标志物复查间隔 |
| 慢病管理 | 家庭监测记录、依从性、不适、复诊安排 | 未记录不能视作达标；不同患者可有不同间隔 |
| 术后随访 | 原医嘱、伤口/功能反馈、已有复诊安排 | 不能把通用术后模板等同具体手术的随访方案 |

[国家卫健委慢性病管理指导意见](https://www.nhc.gov.cn/jws/c100073/202510/3974d142eb1c4dd385b6e880f8617dcc.shtml)强调连续管理和分层服务；[WHO 连续性与协同照护](https://www.who.int/publications/i/item/9789241514033)提供组织层面的参考。本地产品应支持个性化安排、交接和回看，不冒充自动诊疗服务。

### 4. 后续优先级

- 高优先：未联系上的再次联系队列；待回报检查与结果回收的关联；关闭软件后的到期补偿；患者来源、联系对象、知情状态。
- 中优先：从既有医嘱生成可核对计划草稿；多节点模板的科室版本与出处；随访覆盖率、未完成原因统计。
- 需真实通道再验收：企业微信回调、发送失败重试、患者身份绑定、实际送达。配置入口可用不等于已验证真实企业微信通信。
- 不采用：无医生核对即自动修改处方、自动把回复记作正式诊断、把所有消息或提醒算作已完成随访。

## 四、临床试验入组初筛

### 1. 数据来源

- [ClinicalTrials.gov API v2](https://clinicaltrials.gov/data-about-studies/api-migration)：可按 NCT 注册号读取结构化公开记录。本轮采用固定官方域名读取，不接受任意网络地址。
- [药物临床试验登记与信息公示平台](https://www.chinadrugtrials.org.cn/)：国内药物试验原始登记信息核对入口，[国家药监局政务服务说明](https://zwfw.nmpa.gov.cn/web/taskview/11100000MB0341032Y100207202900001)确认该登记途径。本轮提供原站入口，没有冒称完成国内注册平台 API 对接。
- [中国临床试验注册中心](https://www.chictr.org.cn/)：提供网页核对入口；未宣称已完成批量接口对接。
- [WHO 对 ChiCTR 的说明](https://www.who.int/tools/clinical-trials-registry-platform/network/primary-registries/chinese-clinical-trial-registry-%28chictr%29)：确认其注册网络位置。
- [NCI 试验查找步骤](https://www.cancer.gov/research/participate/clinical-trials-search/steps)：适合参考患者资料准备、资格条件及研究团队联系过程。

### 2. 初筛记录必须表达的内容

试验名称、注册号、方案或注册记录版本、来源、研究中心、招募状态、入选标准、排除标准、患者、每项判断、依据日期、缺失资料和核对历史。

入选条件的“是”代表满足；排除条件的“是”代表触发排除。未知独立保存，不能算成满足或没有排除条件。即使逐项核对完成，最终状态仍是“待研究者确认”，不展示“保证入组”。

注册记录可能落后于中心实际状态。导入时保留最近更新日期。涉及多个队列或复杂标题时不自动拆成简单统一条件，以免丢失逻辑、阈值或时间窗。医生可保留原文并补全标准。

### 3. 本轮实现方向

独立导航、方案上传/录入、NCT 读取、逐项初筛、出处记录、患者间隔离、版本冲突提示、历史记录、草稿恢复、打开患者任务辅助分析。后续可扩展按疾病/地区/招募状态搜索，但不能用关键词命中代替资格判断。

## 五、本地知识库

### 1. 一个库必须说明什么

- 名称：例如“肝癌诊疗参考”。
- 收录什么：来源和范围。
- 什么时候用：任务触发场景，供人和助手选择。
- 限制：适用人群、版本、科室规则或不能解决的问题。

指南、书籍、科室流程、药品说明书可以分库。患者个人资料仍留在患者档案，避免把个体资料默认变成通用知识。

### 2. 导入与检索质量

支持图片、PDF、Word、Excel、TXT、Markdown、CSV、JSON。扫描图片走本地 OCR，入库前可核对抽取文字。资料保存成功不等于语义索引成功；关键词检索可以独立使用。

每份来源保留名称、机构、年份、版本、链接、内容哈希和行号。新导入默认“来源待核对”，医生核对版本后可标记使用状态。停用来源不参与默认检索，但原文仍可追溯。

指定知识库时未命中必须明确返回未命中，不能偷偷跨库。相同内容可分别出现在不同用途的库。长段落需要按字符长度进一步分块，否则只嵌入前几千字会丢掉文档后半部分的语义覆盖。

### 3. 可以建立的初始库（建议，不自动填充医疗内容）

| 库 | 使用场景 | 使用限制 |
| --- | --- | --- |
| 疾病指南与共识 | 核对分期、治疗选择、随访依据 | 核对年份、地区、适用人群和更新 |
| 科室工作规范 | 文书、随访流程、转诊协作 | 科室规则不等同外部循证证据 |
| 药品资料 | 查说明书、注意事项、监测要求 | 不能把说明书检索当作完整相互作用审核 |
| 常用文献 | 阅读原始研究及方法、结果 | 区分摘要和全文、研究人群和当前患者 |

## 六、全模块验收视角

| 模块 | 医生需要完成的任务 | 必查异常 |
| --- | --- | --- |
| 新任务 | 直接问问题、带资料或关联患者 | 无患者、切换患者、失败重试、取消、历史不串入 |
| 上传建档 | 多份材料自动整理，后台继续，核对后建档 | 重复文件、单份失败、刷新、旧失败与新患者隔离 |
| 患者列表 | 快速找人、卡片浏览、搜索、归档恢复 | 同名患者、窄屏、空列表、分页 |
| 患者档案 | 概览找重点，各临床页签读完整资料 | 未知过敏、历史用药、同日冲突、不同检验单位 |
| 诊疗辅助 | 提出当前问题、找相似病例或文献 | 缺指南、只有摘要、源证据不足、不自动生效 |
| 随访 | 找待办、记录联系、补充更正、安排下一次 | 未接通不能当完成、重复提交、跨患者、重启 |
| 临床试验 | 对照指定方案、保存缺口与证据 | 排除条件方向、版本冲突、患者资料变化、复杂队列 |
| 知识库 | 按用途组织、导入、检索、阅读和引用 | OCR 空结果、语义服务离线、来源停用、跨库误检 |
| 通用项目与工具 | 文件/浏览器等工作面板、普通问答 | 面板开关、大字模式、目录切换和草稿保留 |
