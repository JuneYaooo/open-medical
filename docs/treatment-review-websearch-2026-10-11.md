# 治疗方案评估接入联网搜索与一键入口加固 · 0.9.89

日期：2026-10-11。功能清单 P0「一键 AI 审核治疗方案（依据含网络搜索、知识库、文献）」的补齐轮：证据源加入联网搜索，患者页一键入口改显式路由。全部合成数据验证。

## 交付范围

- **证据源三级递进**：评估工作流（`patient-assessment`）的工具面在知识库、文献检索之外保留内核 `web_search`（联网引擎链：SearXNG → Brave → 360 → 必应 → DuckDuckGo，按相关性切换）。指引更新为固定顺序：知识库 → 文献检索（最多 2 次）→ 联网搜索（最多 3 次，独立预算 `ASSESSMENT_WEB_LIMIT`）。
- **非全文边界**：联网搜索用于定位指南/共识的发布机构与版本线索；搜索摘要与结果页不是全文，不得当作指南条文引用，引用时注明来源机构与「非全文」；只传脱敏医学关键词（不含姓名、病历号、具体日期），沿用既有外发纪律。
- **一键入口显式路由**：`prepareSend` 接受显式 `workflow: "patient-assessment"`（与 patient-intake 同构），患者页「诊疗辅助 → 准备诊疗评估」按钮随草稿携带该字段（`pendingWorkflowRef` 带到医生手动发送的那一次），不再依赖草稿文本命中正则——医生改写草稿措辞也不会掉回普通问答模式。正则路由保留，两者互补。
- 联网搜索调用计入既有研究预算（18 次工具调用上限）与外发审计事件，不新增权限面。

## 验证

新增/更新 `tests/patient-assessment.test.mjs`（6 项全过）：

1. 既有用例更新：评估工具面断言 ≤12 且包含 `web_search`、仍不含 `code_execute`。
2. 新增：显式 workflow 在消息不匹配正则时仍路由到评估工作流并交付草稿；同消息不带字段则走普通会话不产生评估产物。
3. 新增：`web_search` 预算包装——前三次放行（引擎失败属正常结果）、第四次以 `ASSESSMENT_WEB_LIMIT` 拒绝，工具定义保留。

## 边界

- 搜索摘要不能替代全文：能确认官方来源时在草稿的 infoGaps/concerns 提示「可全文入库后复核」，全文入库仍走既有 knowledge_ingest 流程，本轮不在评估工作流内自动执行。
- 真实引擎链质量（SearXNG/Brave 未配置时走 360/必应/DuckDuckGo 公共源）未在本轮做实网验收；测试只验证预算与工具面，不依赖网络成功。
