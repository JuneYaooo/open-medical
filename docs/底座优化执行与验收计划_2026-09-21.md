## A：交付证据进入默认工作区链路（P0）

位置：`server/core/workspace-service.mjs` execute/prepare/publicWorkspace；`agent-runtime.mjs` onDelivery；`delivery.mjs`；`domain-adapter.mjs`；`session-bridge.mjs`；前端 outcome 消费处。

问题：工作区没有传入 onDelivery，也不保存 delivery/outcome。只回复“已创建 report.md”即 completed，文件不存在。MedicalRuntime 的部分验证不能覆盖 WorkspaceService 和基于它的会话桥。

实施：
1. 明确区分运行结束 completed 与成果 outcome=answered/delivered；问答无需文件，执行请求无证据不能标记 delivered。
2. 将可测试的交付检查接入 WorkspaceService。只采集本次 run 的已应用修改、当前可读文件及 hash、当前产物、真实测试/执行回执；pending/rejected/failed、旧文件和旧 run 证据不能算本次交付。失败退出码不能变成验证通过。
3. 支持显式完成要求，并兼容旧请求；对无法可靠推断的意图保守报告，不凭几个中文词认定所有任务。文件存在只证明产物存在，不等于满足所有内容要求。
4. 持久化及公开投影 delivery/outcome；统一任务页与会话桥读取。验证失败或异常有结构化 gaps，不能静默伪装交付；取消不应落 completed。
5. 不强制每轮工具调用；不要设计无限验证自循环。保留现有审批语义。

验收：独立服务探针覆盖空口创建文件、纯问答、真实写入并核验 hash、旧文件冒充、待审批、拒绝审批、命令非零退出、证据检查异常；重载和会话投影保持结果。当前已复现基线：`completed/delivery=null/outcome=null/fileExists=false`。

## B：可用能力与执行后端一致（P0）

位置：`server/agent.mjs:capabilitySnapshot`；`server/core/code-mode.mjs`；`process-runner.mjs`；`extensions.mjs`；`tool-registry.mjs`；`workspace-service.mjs`；通用平台能力 API。

问题：code_execute 被视为不依赖 Docker，实际需要容器；就绪快照主要查 daemon，不检查镜像；模型工具列表主要按权限过滤，与 UI 状态分裂。

实施：
1. 将能力就绪判定提取为通用核心模块/接口，由真实执行依赖决定，医疗和通用入口共用，不在 agent.mjs 再手写工具名单真相。
2. process/code/terminal 等按真实后端、镜像及配置判断；authorized、ready、executable 分别表达。未知能力不能无条件伪造 ready；给出稳定原因码和补救信息。
3. 同一快照用于模型发现和界面；当前不可执行的工具从模型可调用列表移除，或提供明确不可执行状态的发现机制。禁止把缺工具解释成任务已完成。
4. 探测应有缓存/失效或按轮复用，避免每个工具/每轮重复同步 docker info 阻塞；执行前仍保留权限与环境校验，不能信任过期快照。

验收：Docker down；daemon up 镜像缺失；配置镜像存在；无权限；code_execute；通用/医疗入口一致；依赖恢复后状态更新；现有 capability 测试错误假设必须修正并测试实际执行依赖。无需安装或启动 Docker证明不可用分支；真实容器未测必须标记。

## C：面向仓库的代码检索（P1）

位置：`workspace-files.mjs:search`；`workspace-service.mjs:search_files`；文件权限工具相关测试。

问题：仅 query 参数、字面匹配，100 文件/50目录/深度5，截断后无查询路径或游标，较大仓库漏查。

实施：
1. 保持旧 query 调用兼容，增加 path、glob、字面/正则、大小写、上下文、输出模式和可继续分页参数；可拆 file glob/content search 工具但旧 API 必须保留。
2. 优先使用受控 ripgrep argv（不拼 shell），支持可取消/超时/输出预算。明确 rg 不可用的等价或受限降级行为，不能谎称扫描完整。
3. 保护目录、秘密文件、越界、symlink 边界与旧 WorkspaceFiles 一致；不能直接 rg 全仓库后仅过滤输出而绕过禁止读取路径。遵守忽略规则，避免 node_modules/.git 扫描。
4. 限制返回量而非固定只查前100文件；结果包含路径、行号、截断/分页信息；无结果区分完整检索与未完成检索。

验收：>100文件中末尾目标、深层目录、指定子路径、中文/空格路径、glob、正则、上下文行、分页不漏不重、隐藏/密钥/符号链接拒绝、取消/超时、rg 不存在降级；不以“提高100为1000”解决。

## D：搜索与正文读取的可信降级（P1）

位置：`server/core/web-tools.mjs`；`browser-tools.mjs` URL 策略；web-search 测试。

问题：全部不相关时仍返回 fallback 且无质量标志；配置 SearXNG 失败和其他源语义不统一；抓取拒绝全部重定向、粗糙正文抽取，超过50000字符无法继续读取。

实施：
1. 统一结果 contract：query、engine、results、质量/降级状态、warnings、检索时间；无结果/源失败/低相关分别表达。低相关不能包装成正常相关结果；调用方可主动重搜。
2. 增加域名/时间过滤能力，声明哪些后端实际支持；不支持时本地过滤或显式说明，不能假装生效。保留 SearXNG/Brave 与免密链路，失败策略可测，取消立即传播。
3. 正文抓取支持有限重定向，每跳重新验证 URL/来源权限，禁止借重定向扩大权限；维持响应字节上限。
4. 支持正文分段读取，提供稳定来源 hash、offset/nextOffset/totalChars 或等价元数据，保持旧 url 调用兼容。对跨次内容变化明确提示；不要承诺动态页面/PDF 已支持。
5. 改善正文抽取和实体解码，保持标题/段落/链接可用；能用现有依赖则不随意引入大型依赖。引文可绑定来源和片段位置，不只剩摘要。

验收：全部不相关、全部失败、单源失败、正常结果、取消、域名过滤、时间过滤支持/不支持、授权跳转/越权跳转/循环、长文分页覆盖及内容变化、中文编码。测试使用受控 fetch/本地夹具，真实搜索另行冒烟，不访问患者资料。

## E：模型感知上下文预算（P1）

位置：`agent-runtime.mjs`；`context-manager.mjs`；`model-profiles.mjs`；`providers.mjs`；`provider-request.mjs`。

问题：按 JSON 字符数压缩，不统一计入工具 schema、模型窗口、输出预留；历史摘要不能作为任务事实的唯一来源。

实施：
1. 增加统一预算计算：模型 context window、output reserve、工具定义开销、消息估算；保留 maxContextChars 硬保护和旧配置兼容。准确 token 不可用时标注 conservative estimate，不伪称精确。
2. 安全使用 provider usage 校准，不把累计总usage或输出token当本轮输入；多模态需保守预算/明确未知。
3. 压缩触发与模型请求使用同一预算；压缩请求自身也受窗口约束。异常/连续失败有有限恢复或清楚失败，不无限重试。
4. 保持 system、最近用户、完整工具批次以及持久化计划/授权/已发生副作用/待办事实；归档可回查。避免另建与 store 冲突的全新状态机。

验收：小窗口模型、工具schema占大头、中英文/代码、超长单条、超长工具结果、压缩失败、工具批次不拆散、归档回读、旧配置、不同模型切换预算变化。真实长模型任务未测不冒充。
