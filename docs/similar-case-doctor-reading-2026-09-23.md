# 老年医生的相似病例阅读体验（0.9.28）

相似病例不再复用通用产物验收界面：打开“查看病例详情”进入独立阅读页，移除字段校验侧栏、版本切换及默认确认/退回按钮。可选的医生核对意见单独折叠，原审计与核对功能仍可使用，查看资料无需完成复核。

主要阅读次序：疾病与患者信息 → 治疗经过/用药/结果 → 相同的地方 → 需要注意的不同 → 双方原文。正文 16px，次级信息 14px，增大点击区域并加强文字对比。相似度降低视觉权重，保留规则说明；长英文文章标题放在原文区域，病例以已核对的中文疾病字段命名。

治疗结果只允许使用候选资料中的连续原文作为依据。缺失资料显示“资料未说明”，不推断疗效或生存结局。旧报告没有结构化字段时保持未知。

验证：浏览器覆盖阅读页开启、无校验清单/默认确认按钮、可选核对记录默认收起、比较与原文、返回操作；相关 8 项回归测试通过，治疗结果引用验证断言通过，lint 和构建通过。未向正式患者数据加入测试记录。
