## 一、定位与设计原则

**定位**：面向医生的个人医疗 AI 工作台。对话是唯一主入口，能连接一切功能；患者信息查看是前端友好度的第一优先；文献、科研、溯源是嵌入场景的证据层，不是独立目的地。

**三条核心原则（产品负责人定调）**：

1. **对话式入口，能连接一切功能**——任何功能必须能从对话发起或调用，不存在对话到不了的功能孤岛；功能页只是对话的备选入口。
2. **前端交互为用户友好度服务，第一优先是患者信息查看**——患者速览、趋势、时间线做到"一眼可读"；查看信息永远优先于录入信息。
3. **文献、科研、内容溯源，前端只是把它们更友好地嵌入场景**——以引用气泡、出处角标、检索面板等嵌入式组件存在，不做成独立目的地。

**四条支撑原则（自对标产品提炼）**：执行透明（步骤流可展开、结论带出处）｜交付可验收（文书一律草稿+验收视图）｜分档授权本地默认（患者数据不出本机写进界面）｜上下文可视（预算/压缩/检索三指示器）。

**评审清单**：任何新功能先过三问——能否从对话直达？患者信息是否一眼可读？文献/科研/溯源是否以嵌入组件服务场景？

## 二、全局框架（所有页面共享）

### 2.1 布局骨架

```
┌ 顶栏 48px：品牌 | 患者胶囊▾ | 本地徽章 | 上下文%·预算%·检索命中 | 设置 ┐
├──────────┬──────────────────────────────┬──────────────┤
│ 左栏 236px │ 中栏（对话执行区，弹性）        │ 右栏 352px    │
│ ＋新任务   │  会话头：‹返回 · 任务名 · 患者胶囊 │ 场景面板：    │
│ 项目→任务  │  ·阶段条（文书任务）            │ 材料|知识|产物│
│ 患者列表   │  消息流：步骤流/回答+引用/产物卡  │ ＋场景附加 tab│
│ 工具箱     │         Goal 卡（长任务）       │（速览/搜集/记忆）│
│ 首页/记忆  │  验收视图 = 叠加中栏的验收层     │              │
│           │  composer：上下文chips+输入+符号+档位│             │
└──────────┴──────────────────────────────┴──────────────┘
   参考：屏 0（信息架构总图）、屏 1（主工作台全景）
```

- 窄屏（<1024px）：左栏、右栏收为抽屉；验收视图退化为全屏页。
- 框架不变量：**任何场景不得新开独立窗口或弹走主对话**（R4）；三栏位置永远不变，只有右栏内容随场景切换。

### 2.2 顶栏

| 元素 | 规格 |
|---|---|
| 患者胶囊 | `● 患者：张三 · 男 · 67岁 ▾`，点击下拉切换（最近/分组/搜索/新建）；带高亮描边提示可点；会话内点击=迁移（二次确认）。见屏 7 |
| 本地徽章 | `◈ 数据本地处理` 常驻，是产品主张不是装饰 |
| 上下文指示器 | 上下文占用%、token 预算%、检索命中数三条 mini bar；>60% 变琥珀色 |
| 模式相关 | 模式档位不在顶栏——唯一入口在 composer 右下（2.7） |

### 2.3 左栏

自上而下：`＋新任务` → **项目**分组（可新建，第五章）→ 未归入项目·今日（待复核/进行中/已完成，颜色状态点：琥珀=待复核、蓝=进行中、绿=已复核、灰=独立任务）→ **患者**列表（风险角标 ⚠n）→ 底部：工具箱、首页、记忆面板。

### 2.4 中栏 · 对话执行区

- **会话头**：返回、任务名、患者胶囊、状态徽章；文书任务追加三阶段条（准备材料→整理生成→复核成果），咨询任务显示"咨询 · 不产文书"徽章。
- **消息流**：
  - 步骤流：工具名+结果摘要+耗时，默认收起最近 3–5 步可展开（R3）；
  - 回答：结论 + 引用气泡（`📄 文档 · L120–135`，点击进行号原文）+ 无出处段落标"待核查"；
  - 产物卡：`📄 名称 · draft/approved · vN · 出处 n 条` + [打开验收视图][在对话中修订]；
  - Goal 卡：仅多步产物任务出现——章节×证据清单、校验轮次、暂停/手动接管（R7）。
- **composer**：上方上下文 chips（患者/材料，可移除）；输入区；底部符号体系 `@`患者/资料/指南、`/`命令、`$`技能、`+`附件；右下模式档位（2.7）。

### 2.5 右栏 · 场景面板

骨架固定：材料 ｜ 知识 ｜ 产物 三个基础 tab，允许追加**一个**场景 tab（搜集资料/切换检查单/记忆三层/检索结果）。每个 tab 内是卡片流：卡片 = 标题行 + 元信息 + 命中/摘要 + 动作（`引用进对话` / `查看` / `存入…`）。**卡片动作全部汇入统一收口**（产物→验收视图，资料→三去向）。

### 2.6 验收视图（叠加中栏的验收层）

顶栏：`‹ 返回对话 ｜ 名称·版本·状态 ｜ [预览 | 与上一版差异(n) | 出处对照]`。
主体左列 = 文档视图（diff 用绿增红删、逐句"源"角标）；右列 = 字段校验清单（缺项[让 AI 补充]）+ 复核记录（每次退回原因留痕）。
底部复核条：复核人代号（选填）+ `退回修订` / `✓ 确认通过`。通过 → approved 可发起随访；退回 → 自动生成修订指令回会话。**它不是独立页面，是叠加层**；移动端退化为全屏。见屏 3。

### 2.7 模式档位（唯一写入开关）

`咨询（只读，默认）→ 文书（可写，产物一律 draft）→ 计划（先出方案不动手）→ 自动（本地工具连续执行）`。Shift+Tab 或点击循环；档位决定能否产出 draft（R2）；写档案、外发、删除在任何档位都二次确认。现有"本地/智能"运行模式与外发勾选并入档位语义。

### 2.8 设计 token

延续品牌：主色 `#28735b`（墨绿）、底 `#f4f6f5`、纸 `#fff`；状态色：琥珀=待复核/提示、蓝=进行中、红=风险/错误、绿=通过；正文 12–13px 紧凑密度；圆角 8–12px；字体 PingFang SC。现有 style.css 需收敛为完整 token 集，退役暗色 `--desk-*` 与 `.shell` 死代码（`style.css:172-178`）。

## 四、患者管理专题设计（字段级详细版）

> 患者管理不是一个页面，而是"一个长期对象 + 四个触面 + 一套隐私规则"。对象链：Patient（档案）→ 病例工作区（每患者一个会话）→ Run → Artifact（全走 draft→验收）→ Followup。

### 4.1 位置与切换的裁定

- **项目放左栏（与任务列表同层）——合理，保留**：项目是任务的容器，与 ZCode/Codex 的左栏结构同构；用分组标题与患者列表区分。
- **患者的位置裁定**：患者既是"导航对象"又是"工作上下文"，拆开处理——左栏患者列表只做"找人"；"当前是谁"由顶栏胶囊承担（PHI 永远可见）；"看信息"由右栏速览卡承担（零跳转，第一优先）；详情页只做兜底与编辑。
- **频率依据**：切换患者每天 3–5 次，查看信息 30+ 次——所以点击左栏患者 = 切换 + 右栏速览卡跟随（一次点击两件事），不跳页；[打开详情] 才进详情页。
- `@患者` = 引用 ≠ 切换（R5）。

### 4.2 触面一：患者列表页（P4 · 屏 16）

**布局**：左栏（导航）+ 全宽内容区：搜索框（姓名/拼音/首字母，↑↓ 键盘切换选中）+ 建档按钮；筛选 chips（全部/重点关注/⚠有风险/随访逾期/本月新增，数字实时联动）；排序（最近接触/风险优先/拼音）；患者卡片两列网格。

**卡片字段（固定）**：头像｜姓名｜性别·年龄｜诊断串（1–3 个）｜过敏红字｜风险 ⚠n｜下次随访日期｜最近成果状态｜最近接触时间。当前患者卡片描边高亮。

**交互**：点卡片 = 切换为当前患者（右栏速览卡跟随）；`[打开详情]` = 进详情页；hover 无额外语义（触屏友好）。

**状态**：空（无患者 → 建档卡常驻同位）｜加载（骨架卡 ×6）｜列表读取失败（重试）｜筛选无结果（"换个筛选试试"）。

### 4.3 触面二：患者速览卡（P4a · 屏 2，字段级）

| 区域 | 字段/内容 | 规则 |
|---|---|---|
| 卡头 | 头像、姓名、性别·年龄、诊断串（≤3）、过敏红标、◈本地徽章 | 过敏永远红显；缺项不显示占位 |
| 当前用药 | 在用药物 chips，最多 4 个 + "＋n" | 含剂量；停用不显示 |
| 近期检验 | 最近 3 项：名称 + 数值 + 单位 + 趋势线/达标态 | 数值优先于表格；异常值琥珀 |
| 关键事件 | 最近 3 条（就诊/手术/出院），带日期 | 每条可点开来源 |
| 动作条 | [让 AI 解读趋势] [生成随访小结] [查看完整档案] | 全部走对话或详情页，不新增页 |

只读；数据源=概览+临床资料读接口；某列无数据 → "暂无 XX 记录"。

### 4.4 触面三：患者详情页（P5 · 屏 17，逐 tab 字段级）

**头部 PHI 条（四 tab 共用）**：‹患者列表｜姓名｜性别·年龄｜诊断胶囊｜过敏红标｜[打开病例工作区]。

**概览 tab（默认，自上而下）**：
1. **风险面板**：扫描条（时间+数量+历史入口）→ 风险卡流（红>琥珀排序）：类型徽章+一句话结论+依据（2 篇，可展开行号）+动作[生成草稿任务｜查看依据｜忽略本次(留痕：不适用/已处理/误报)]；已处理卡保留并回链成果。无风险时折叠为一行"无风险提示 · 昨日已扫描"。
2. **关键事件时间线**：垂直倒序；节点=日期+事件+**来源**（记录名+行号，可点开原文）；筛选：全部/就诊/检验/文书。
3. **成果列表**：日期+名称+状态徽章（待复核/已复核）+[打开验收/查看验收]；只列经此患者工作区产出的 Artifact。
4. **AI 提议**：待确认列表，每条=提议内容+来源+`[采纳写入][忽略]`——**写入档案的唯一通道**。

**临床资料 tab**（唯一可编辑处）：默认只读视图，[编辑]进入；五段：
- 诊断：名称+日期+状态（在诊/痊愈）；过敏史：独立置顶红显（过敏原+反应）；用药：药名/剂量/频次/起始/状态（停用保留不删）；检验：项目/值/单位/参考区间/异常标/日期，同一项目可看趋势；就诊：时间线。
- 每段 `[＋添加]`；保存=字段级变更记录（谁/何时/改了什么）；编辑后相关产物自动回 draft（沿用现有机制）。
- AI 提议采纳后在此出现并标记"AI 来源"。

**消息 tab**：待认领卡（渠道+时间+摘要+[认领到这位患者]）+ 历史消息时间线。**随访 tab**：到期计划置顶 + 计划卡（频率/清单/下次日期/状态）+ [＋安排随访]（仅 approved 成果与手动两种来源）。

### 4.5 触面四：风险与资料（屏 8）

- 扫描时机：每日本地 06:00 + 会话结束增量核对；规则来源：用药冲突（medication_safety_check）/随访逾期（followups）/检验趋势；误报结构化回收。
- 资料搜集：对话发起 → 右栏"搜集资料"tab，按类型与可信度分级 → 三去向（患者附件/知识库=同一入库动作/引用进对话）。

### 4.6 右栏"患者上下文"面板（详情页常驻，屏 17）

患者记忆（条数+摘要+[管理记忆]）｜外发授权（会话级有效，切换即重置，[撤销]）｜病例工作区（文件数+[打开工作区]）。随切换整体跟随，不串档。

### 4.7 案例：张三的门诊日

切到张三 → 速览卡答家属退烧药问题 → 风险卡一键生成用药建议 → 验收通过风险闭环 → 科普存入患者附件 → 下午出院小结归档、时间线可见、随访发起。全程不离开对话。

## 五、项目体系专题设计

> 项目 = 长期容器：把目标、任务、文献、数据、记忆归组在一起。对标 ZCode/Codex 的项目体系，但为医疗增加"类型预置结构"与"记忆种子"。

### 5.1 对象关系矩阵

| | 患者 | 项目 | 任务（会话） |
|---|---|---|---|
| 本质 | 长期档案 | 长期容器（目标驱动） | 一次对话式工作 |
| 数据 | PHI，本地 | 脱敏聚合数据 | 当次材料范围 |
| 记忆 | 患者记忆（随访偏好等） | 项目记忆（目标/纳排/方法论） | 会话上下文（短期） |
| 归属 | 患者任务永远归患者 | 项目内任务默认绑定项目 | 可挂患者、可挂项目、可独立 |

**边界**：患者任务不进项目；科研项目里看患者数据=只读脱敏聚合；一个任务只归属一个容器（患者 or 项目 or 独立）。

### 5.2 项目类型与预置结构

| 类型 | 预置结构 | 典型屏 |
|---|---|---|
| 科研课题 | 6 阶段 stepper（检索→筛选→精读→证据表→分析→写作）+ PICO 卡 + 文献集 + 数据 tab + 论文产物 | 屏 10/11 |
| 专病知识库 | 子库分组 + 上传流程 + 知识库体检 | 屏 9 |
| 日常事务 | 任务清单 + 文书模板 | — |
| 自定义 | 空结构，对话中逐步沉淀 | — |

### 5.3 生命周期

**新建**（4 字段：名称 / 类型 / 目标描述 / 知识子库）→ **运行**（项目内新任务默认绑定；文献、数据、成果持续归组；项目记忆随每晚整理沉淀）→ **结项**（产出清单归档：任务/文献/成果/数据；项目记忆转只读、可导出）。

### 5.4 新建项目流程（屏 6）

1. 名称；2. 类型（决定预置结构）；3. **目标描述 = 项目记忆种子**（AI 在课题内延续这些背景）；4. 配套知识子库（新建"课题文献"/挂接临床指南）。创建后自动：项目记忆空间、默认绑定规则、本地存储声明。全程 < 1 分钟。

### 5.5 项目页布局（屏 6/10）

```
┌ 头部：‹项目 | 名称+类型徽章 | 阶段 stepper（科研 6 阶段） | [＋新任务] [设置] ┐
├ 概览：目标卡（=记忆种子，可编辑） | 进度统计（任务 n / 文献 n / 成果 n）
├ tabs：任务 | 文献/子库 | 数据 | 成果
└ 右栏：场景面板（课题文献检索结果 / 项目记忆入口）
```

### 5.6 项目记忆与知识子库

- 种子（目标描述）→ 运行沉淀（每晚整理项目内会话，提炼纳排标准、方法论）→ 注入（项目内任务回答头部"参考项目记忆 N 条"）。
- 知识子库按项目隔离，可挂接全局指南库；文献集自动去重、按 PICO 匹配度排序。

### 5.7 案例：课题立项五分钟

新建"2型糖尿病管理路径研究"→ 目标描述写入（含目标期刊）→ 自动建课题文献子库 → 首页检索 8 篇按匹配度入集 → 发起第一个任务"第 3 批文献筛选"。项目记忆从此开始累积。

## 七、统一交互规范（十条全局裁定）

任何新场景与规则冲突时，**改场景，不改规则**：

1. **产物唯一生命周期**：draft → 验收视图 → approved/rejected；编辑回 draft。所有"生成草稿"入口（文书/风险建议/工具结果/统计图/论文/就诊备注）汇到同一验收视图。
2. **模式档位唯一且全局**：咨询/文书/计划/自动，入口唯一（composer 右下）；写档案、外发、删除任何档位都二次确认。
3. **回答三件套**：步骤流（可折叠）+ 结论 + 出处；无出处段落标"待核查"；样式全场景一致。
4. **右栏 = 场景面板**：骨架固定，内容随任务切换；任何场景不得新开独立窗口或弹走主对话。
5. **患者上下文唯一规则**：@患者=引用≠切换；切换只有三入口；PHI 必须可见"当前是谁"；外发授权按患者隔离、切换即重置。
6. **待办唯一收口**：今日（左栏）+ 待复核（徽章+队列）；风险、随访、复核、记忆确认全部汇入，不设第三个通知中心。
7. **长任务只认 Goal 卡**：多步产物任务显示 Goal 卡；单步问答没有。
8. **记忆注入可见**：回答标注"参考了 N 条记忆"，可展开可屏蔽；三层各归各位，患者记忆随切换跟随。
9. **溯源形态按对象固定**：文档=行号区间；患者数据=记录+时间；文献=DOI/期刊年；统计=队列条件+沙箱参数。
10. **一切长任务可中断可回溯**：暂停/接管常在；失败留运行记录；"忽略/退回"结构化留原因。

**易冲突点裁定表**：

| 潜在矛盾 | 裁定 |
|---|---|
| 资料搜集"存入知识库" vs 知识库构建入库 | 同一动作：AI 打标→归子库→索引，入口文案统一 |
| 速览卡 vs 患者详情 | 速览=只读摘要嵌对话；详情=编辑+全量；数据同源 |
| 出院小结 Goal vs 论文 Goal | 同一组件（R7），仅清单内容不同 |
| 咨询 vs 文书 | 档位决定能否产 draft；咨询显式"存为备注"才产 draft |
| 退回 vs "在对话中修订" | 退回=自动生成修订指令回会话，同一条路 |
| 项目 vs 患者任务 | 患者任务永远归患者；项目只用脱敏聚合数据 |
| 患者记忆 vs 切换 | 患者记忆随切换注入/移除，不串档 |
