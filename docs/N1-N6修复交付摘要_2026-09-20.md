## N1 执行与验收隔离(复核 R1)— self_verified(容器路径 blocked)

**根因**:`validators.mjs` 的 `runNode` 用宿主 `spawn(process.execPath)` 导入被测模块:继承仓库 cwd/环境/权限、无截止时间;`__RESULT__` 无防伪(被测代码可自行打印);`hashTree` 用 `statSync` 跟随符号链接。

**修改**:
- 新增 `scripts/eval-v1/lib/execution-backend.mjs`:`DockerExecBackend`(只挂载测试工作区、`--network none`、最小 PATH 环境、tmpfs /tmp;超时 `docker kill` 容器整体清理)、`UnavailableBackend`(显式 blocked,绝不宿主回退)、`InProcessNodeBackend`/`ScriptedBackend`(显式标记 mock 的自测适配器)。
- 结果协议防伪:随机 32-hex nonce 经 **stdin** 传给 harness(不出现在 argv/env/挂载面),控制器只接受恰好一行 nonce 匹配的结果;断言全部在控制器完成,被测代码自报"通过"不再被采信。
- `runModule`:执行前后对整个测试工作区做哈希快照,篡改即 fail;截止时间 → 任务级 timeout;输出上限 → 有界终止。
- `fixtures.mjs hashTree`:`lstatSync` 不跟随链接;junction/symlink 解析 realpath,越界即 `TreeBoundaryError`;realpath 集合防目录环;文件数/大小上限。
- `run.mjs` 默认注入真实容器后端(`--exec=auto`),`--exec=mock` 显式声明无隔离自测并在报告标记 `execution_backend_mock`。

**验证**(Node 24,tests/eval-execution-backend.test.mjs 12 项:11 过/1 跳过):
- N1-04 无限循环/永久定时器 → 截止时间内结束,任务级 timeout ✓
- N1-05 50MB stdout → 有界终止,控制器不耗尽内存 ✓
- N1-06 junction 指向工作区外/目录自环 → `TreeBoundaryError`,不读取不挂死 ✓
- N1-07 后端不可用/未提供 → blocked,无宿主回退 ✓
- N1-08 伪造结果标记(无 nonce)→ 协议异常拒绝;执行期篡改工作区 → fail ✓
- N1-01/N1-02/N1-03(合法解真实容器执行、答案/宿主秘密哨兵不可见)→ **blocked**:本机 Docker daemon 未运行。测试在容器可用时自动执行(否则带因跳过)。
- 验收器自测 71 样例全绿(31 正确通过/38 错误拒绝/2 缺环境 blocked),C01—C04 经 mock 适配器真实执行断言(已标记 mock)。

## N4 医疗交付按目标核对(复核 R4)— self_verified(真实 MedicalRuntime 链路)

**根因**:`runtime.mjs` 把 `delegatedReceipts.length>0` 当 effects,失败子任务回执也入库;任一回执存在即 delivered:true;沙箱成功可抵消缺失产物。

**修改**(与 N3 共用 normalizeDelivery 语义,不另建状态体系):
- 回执记录真实状态 `{childId, status, ok, artifactCount, error}`;失败回执进 gaps(诊断),不进证据。
- onDelivery 重写:consultation → null(回答型,不因副作用宣称交付);执行类 delivered 必须"通过结构核对的草稿产物存在且无未解决缺口";沙箱成功无产物 → `sandbox_without_deliverable` 缺口;子任务 completed 无产物 → `no_artifact_deliverable` 缺口;草稿结构核对(去元数据键后有非空载荷);交付 note 明确"待复核,不代表医生已确认"。
- 结果分类统一:delivered/unverified/delivery_failed(执行类未完成不再降格 answered)。

**验证**(tests/medical-delivery.test.mjs 5/5,均穿真实 MedicalRuntime 执行链):
