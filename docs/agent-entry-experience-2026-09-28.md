# Agent 入口与业务导航

工作台以新任务对话作为统一起点。用户可以直接描述目标、添加材料；患者和项目作为可选上下文，不再要求先选择临床或通用任务类型。

## 导航结构

- 新建任务：打开未发送草稿或开始新的对话，始终保留在侧栏顶部；窄屏顶栏也提供入口。
- 任务记录：查找已有对话与成果，可筛选待复核、患者关联或项目任务。
- 项目文件：连接本地目录，管理项目资料和文件操作。
- 医疗工作：今日待办、患者、随访、临床试验。
- 资料与工具：文档与表格、文献检索、知识库、临床速查、病例库、科研统计。支持功能关键词和常见同义词检索。
- 设置与连接：模型、医生档案与记忆、随访渠道、按项目配置的高级工具。

原快捷工具箱不再单独维护一套入口。工具使用整页视图，通过页内路径返回目录。患者任务显示关联患者，并可返回其档案。最近对话直接显示，不再要求展开高级菜单。

## 新任务与上下文

默认对话通过现有统一会话运行时执行。关联患者后沿用该患者资料，并在患者会话中创建新的问题；关联项目后先创建独立对话，再提交首页目标。项目新对话使用同一文件夹，不沿用原对话历史；工具权限在新任务中管理。

附件正在上传时不能发送或切换关联对象。已上传材料锁定目标会话，避免把材料误关联给另一位患者或项目。关联患者选择器也提供新建患者入口。

常用示例只用于准备输入；完整模板按需展开。输入和附件在当前应用会话内跨页面保留。“清空草稿”显式重置未发送内容，已保存的材料仍可在任务记录中查找。整页刷新或退出应用不持久化首页未发送正文。

从诊疗辅助、知识库和检索规划进入对话时，预填内容仍为待发送任务。界面明确显示尚未执行，用户核对后发送。

## 科研统计

统计页可以直接上传非空、2MB 以内的 CSV，并自动保存到本地任务、选中该数据文件。也可以使用已有任务中的 CSV。描述统计、组间比较、样本量估算和脱敏导出继续使用原有确定性计算接口。

上传后显示保存位置；刷新后可通过已有任务重新选择文件。上传或计算过程中锁定相关输入，切换数据后清除旧结果。

## 验证入口

- `tests/agent-entry-ui.test.mjs`：统一入口、患者上下文恢复、工具查找、窄屏导航、CSV 上传与统计、项目新对话一次发送。
- `tests/navigation-recovery-ui.test.mjs`：路由恢复、失败重试、材料草稿、患者身份隔离。
- `tests/redesign-scenarios.mjs`：患者、复核、随访、工具等既有业务链路，使用统一导航入口。
- `tests/navigation-ui.mjs`：业务测试共用的患者、工具与建档导航。

本地预览及浏览器测试不替代真实模型质量、外部聊天平台收发或安装包验收。

## 本轮验证结果

Lint、生产构建和差异空白检查通过。完整测试共 944 项，910 项通过、31 项因运行条件跳过、3 项失败。失败均涉及已调整入口的定位：模型按钮文案，以及建档按钮与最近对话中的同名任务。修正入口标识和测试导航后，针对统一入口、医生工作流、模型设置和建档恢复的最终复测共 24 项，23 项通过、1 项真实材料环境测试跳过、0 失败。

完整运行日志与最终专项日志分别保存在 `output/playwright/agent-entry/full-regression.log`、`output/playwright/agent-entry/final-retest.log`。未在修正后再次执行整个 944 项集合。构建仍有既有的大资源块提示。
