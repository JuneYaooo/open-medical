## 已连接的功能

- 同目录多个独立任务；搜索、重命名、置顶、归档和恢复。新任务只继承目录读取范围，不继承写入、Git 或外部操作授权。
- Markdown、GFM 表格、代码高亮和复制；文件引用在右侧打开，支持绝对路径和行号定位。
- 对话独立滚动、固定输入区；右侧文件、行号编辑器、选中代码追问、Diff 审批、运行记录、浏览器截图预览及设置。可调整面板宽度、收起侧栏；窄屏改为上下分区。
- 执行状态、折叠工具记录、待审批入口和成果预览/下载。
- 文本、代码、文字层 PDF 附件；项目技能选择；PNG/JPEG/WebP 添加、拖放和粘贴。
- 图片上传到任务成果库，不修改项目目录。上传限 600KB；目录图片仍支持原有 4MB 限制。支持视觉的适配器通过 `inspect_image` 的 `artifactId` 读取，非视觉适配器不具备图片理解能力。
- 持续终端输出、会话切换、标准输入和停止；验证待审批文件、本地 Git 状态、提交与 worktree 沿用已实现的后端流程。
- 切换任务保留本次页面会话的输入草稿；刷新恢复上次选中的未归档任务。草稿不写入浏览器持久存储。
- 防止旧任务异步加载覆盖新任务；附件组件卸载后忽略迟到结果；限制重复启动和非法运行预算。
- 服务端允许本地 Blob 图片、PDF 和 PDF worker，保留对任意远程 iframe 的限制。

## 验收
