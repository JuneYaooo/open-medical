# 文献检索式规划（2026-09-22）

此前工具把 query 原样发送，中文主题易出现没有意义的零命中。此次让现有 Agent 负责语义改写，工具负责可核验执行，未硬编码疾病翻译表，也未绕过用户模型授权。

- 工具说明和医疗运行纪律要求：提取核心概念，将非英文主题改写成英文关键词；2–4 组覆盖核心概念、同义词和宽泛检索。歧义保留不同解释，不能添加未描述的诊断，不冒称 MeSH 已核实。
- queries 支持有界分组搜索，保留每组检索式、实际来源、取回数量、失败状态；按 PMID / DOI 去重并记录命中组。
- 中文等非拉丁文字直接传 query 会在联网前返回需改写提示，Agent 应自行重新调用。英文精确查找仍可单 query；保留 déjà vu 等带重音术语。
- 零命中不等于没有文献；工具失败不等于零命中；部分组失败会标 partial，全部失败抛错。取回候选仍须读摘要核实相关性。
- 文献面板输入中文可打开预填主题和年份限制的任务，用户发送后由助手规划并检索。未发送时不运行模型。

验证：40 项文献、界面与会话测试通过；Lint/构建通过。当前配置的真实 deepseek-flash 模型将“颞叶癫痫感知性症状”改写为 4 组英文检索式，PubMed 每组取回 3 条，去重后 12 条候选；候选数量不代表相关性评审通过。回执位于 output/literature-rewrite-20260922/live.json（不入 Git）。

参考：PubMed 官方帮助 https://pubmed.ncbi.nlm.nih.gov/help/ 。相关主题确有文献，例如 https://pubmed.ncbi.nlm.nih.gov/23649108/ ，此前零结果不应表述为没有论文。
