## 仍未修复的具体交付问题

1. `desktop/install-mac.command` 先删除目标再复制；如果从已安装应用中再次执行，源和目标相同，会删除源应用。安装脚本不应投入交付。
2. `desktop/main.cjs` 编辑配置调用 `/usr/bin/open -a TextEdit`，没有 Windows 分支。
3. `scripts/package-desktop.mjs` 的 macOS 快速路径复用本机 Electron，未校验请求架构；指定 x64 可能得到错误架构标签。Windows 安装脚本输出路径固定 x64。
4. `scripts/verify-offline-package.mjs` 只做有限文件存在检查；敏感数据检查在包输出顶层，未递归检查实际应用目录。它不能证明完整离线安装或打包无敏感数据。
5. minimal 模式只向模型提供材料的有限预览，禁用读全文工具后不等于完整材料问答能力。
