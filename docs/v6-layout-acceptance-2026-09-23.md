# V6 前端改造验收

版本：0.9.18；参考：http://127.0.0.1:53784/v6/ 及其 DESIGN.md（2026-09-23 修订）。

## 已实现

- 常驻“医疗业务”和“通用工作”两组导航：患者、随访、科研；任务、项目、工具。全局新建任务始终可见，长列表放入“最近使用与快捷入口”，固定项目最多展示三项。
- 默认任务首页复用 WorkbenchHome，保留大输入框、临床/通用任务、患者关联、附件、技能、运行选项、今日待办及常用场景。
- 新增真实项目目录：搜索、固定、归档、恢复、连接文件夹、打开既有工作区。修正指定项目可能被上次选中项目覆盖的问题。
- 任务记录聚合既有医疗会话和通用工作区索引，以后端类型与原 ID 区分，不复制对话或重建项目。
- 新增工具目录、分类和搜索。医疗工具直接打开；浏览器、终端与连接工具先选择授权项目，打开真实项目对应面板，不将演示状态标记为已连接。
- 任务和项目工作区支持工作区、AI 半屏、AI 全屏。模式切换保留当前组件和输入草稿，文件仍在原工作面板中打开。
- 字号移至右上角，保留大字偏好。调整系统中文字体层级、颜色、间距、目录行、焦点提示与窄屏文字导航。
- 保留患者可视化档案、资料上传与解析、后台任务、失败恢复、原文来源、随访和临床编辑。

## 本轮边界

V6 中的微信联系人绑定、统一患者事件模型、研究队列仍是后续业务工作，不复制原型的虚构数据、绑定状态和模拟回复。全局显示方式目前用于已打开的任务和项目；患者、随访、科研页面不会因切换显示模式自动新建或发送 AI 任务。完整产品方案保留在原实施文档中。
