# 医生提醒与飞书知识库机器人

医生提醒用于把待办数量送到医生常用的消息渠道；知识库机器人用于把适合分享的资料带到协作群。两者分别配置、默认关闭。

## 每日医生提醒

打开「设置 → 医生提醒」。微信通过扫码连接接收提醒的医生账号；飞书通过群「自定义机器人」的 Webhook 连接。签名校验启用时填写签名密钥；关键词校验可使用 `Open Medical`。

保存连接后，可以发送测试消息并在收件端确认。选择每日时间与时区，启用并保存。每日摘要统计今日及逾期随访，以及需要跟进的患者数量，同一位患者去重计数；归档患者和已结束事项不参与。消息不含患者姓名或病历内容，处理时返回工作台的「随访」与「今日待办」。

同一渠道、同一连接每天只发送一次摘要。没有待办时不发送。网络中断可能导致送达状态不确定，此时不会自动重发；核对收件箱后，可以使用界面中的重试按钮。平台接受请求不等于收件人已经阅读。

应用需保持运行并联网。应用退出期间不发送，重新运行后按当天待办重新汇总。断开连接会删除保存的连接凭据并停用提醒。凭据使用本机加密保险库保存。

微信扫码能力参考 iLink 接入方式，可用性取决于账号及平台服务；平台拒绝发送时，界面会显示失败并保留重试入口。

## 飞书群查询知识库

1. 在「知识库」创建按用途组织的资料库，导入文档，核对来源并将资料标为已复核。选用适合群内分享的资料。
2. 在[飞书开发者后台](https://open.feishu.cn/app)创建企业自建应用，开启机器人能力。添加 `im:message.group_at_msg:readonly` 和 `im:message:send_as_bot` 权限；显示群名称还需获取群信息权限（`im:chat:readonly`）。
3. 在「事件与回调」选择使用长连接接收事件，订阅 `im.message.receive_v1`。保存连接以建立长连接，再按飞书后台要求保存订阅、发布应用并完成组织审批。
4. 打开「设置 → 飞书知识库机器人」，填写 App ID / App Secret，选择允许分享的知识库，启用并保存。查看连接状态。
5. 在飞书群添加机器人并 @ 它一次。返回设置刷新群列表，勾选允许使用的群并保存；随后再次 @ 机器人提出问题。

未授权群不会收到回复。普通群消息、私聊以及仅 @ 其他人的消息不会触发查询。授权群可查询所选库中全部已复核资料，包括之后新增并复核的资料；未复核或已停用资料不会被引用。患者档案和独立病例库不参与查询。

当前版本在本机按关键词检索，回复相关原文、文档标题、所属库和行号，不生成个体诊疗结论。没有依据时直接说明未找到；可以缩短问题或改用具体关键词。查询不会调用外部嵌入模型，但匹配的资料摘录会通过飞书发送至授权群。

关闭机器人、撤销群授权或更改资料库范围后，新的请求按新配置处理。群内已经收到的回复不会撤回。桌面端需保持运行并联网，长连接不需要为本机配置公网回调地址。

飞书[自定义机器人](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)只负责主动发送提醒；知识库查询使用自建应用的[接收消息事件](https://open.feishu.cn/document/server-docs/im-v1/message/events/receive)和[回复消息接口](https://open.feishu.cn/document/server-docs/im-v1/message/reply)。
