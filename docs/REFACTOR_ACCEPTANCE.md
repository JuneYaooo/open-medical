# 0.4 通用内核重构验收 · 2026-09-10

本轮完成了可运行的通用内核、独立 CLI 与工作区，以及医疗适配器接入。**仍未达到 Codex / DeepSeek Harness / Hermes / WorkBuddy 全部能力等价。** 本记录区分代码完成、实际运行测试和仍未实现的功能，不以接口名称或通过测试数量替代完整需求验收。

## 已完成并接通

1. **共享 AgentRuntime**：医疗与通用工作区真实使用同一个模型/工具循环；预算、流式响应、取消、工具调用授权与错误处理共用。医疗系统规则和业务入口集中在 `server/domains/medical.mjs`。
2. **独立通用接口及 CLI**：`server/core/index.mjs` 提供导出；`npm run workspace --` 可在不启动医疗服务器的情况下创建工作区、执行任务、审批、分支、查询轨迹。独立数据库不创建患者表。
3. **本地工作区 UI/API**：授权目录、目录浏览、文本读取与字面检索、版本哈希、前后内容展示、逐项批准/拒绝、撤权、冲突防覆盖，以及已修改文本的回退提案。
4. **运行与分支**：SQLite 持久消息与事件、流式执行、停止、重启中断标记、部分输出保存、按已结束运行截点分支并继承可见对话。分支共享原文件夹；不自动继承写入授权或待审批动作。
5. **通用子任务**：独立上下文、父任务范围、只读、禁止递归、最多 3 个、取消联动及用量汇总。
6. **通用计划**：持久单次/固定间隔、暂停与重新授权恢复、避免重复执行、授权/模型变化后暂停；计划不会自动批准文件修改。
7. **本地模型连接**：明确的 `AI_PROVIDER=local` 配置，允许无 API Key 的回环 OpenAI-compatible 服务，禁止非本机地址和自动重定向。通过合成协议服务验证，未安装/验证真实模型权重。
8. **基础设施迁移**：模型适配器、技能发现与读取、Python Sandbox 迁入 core，医疗旧导入路径兼容保留。技能路径增加真实路径与符号链接逃逸检查。
9. **桌面修复与交付**：Mac 安装改为先复制后替换，避免重复执行删除自身；Windows 配置编辑器改为 Notepad，关闭窗口正常退出；修复打包架构选择和安装脚本路径；离线资源检查递归扫描实际 app 目录。
10. **预览数据保护**：8792 更新前完成一致性备份与完整性校验，确认无正在运行的任务后重启。预览现在使用持久目录，退出不会再自动删除其中数据。
