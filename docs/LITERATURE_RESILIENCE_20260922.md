# 文献检索容错与发布（2026-09-22）

问题：文献源单次请求达到 20 秒上限即失败，没有重试与备用源。

修复：每次请求设 8 秒超时，包含响应体读取；网络失败、超时、HTTP 408/429/500/502/503/504 最多重试一次，重试间隔 400ms。PubMed 保留请求节流。检索源仍不可用时切换 PubMed / Europe PMC，沿用查询、年份、数量和排序。结果与界面明确标记实际来源及切换原因、检索范围差异。备用结果不写入首选源缓存，以便下次恢复首选源。有效零结果不触发切换；两个源都失败明确报错。摘要获取同样受请求重试保护，但不伪造备用摘要源。

验证：文献测试 11/11；真实 PubMed、Europe PMC 检索各返回 2 条；模拟首选源超时后真实备用源返回 2 条。全量 743 项：726 通过、0 失败、17 项 Docker 环境测试跳过。Lint、构建通过。
