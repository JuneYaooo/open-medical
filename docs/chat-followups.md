# 聊天随访

微信与企业微信的连接在“设置 → 随访连接”分别配置。聊天内容先进入待复核草稿，确认后才登记为随访联系记录。

## 微信桌面

当前应用内适配支持 macOS，使用本地原生窗口控制与 Apple Vision。需要本机微信已登录，桌面组件具有辅助功能和录屏权限。

1. 在设置中先点击“检查微信与权限”；通过后在微信核对当前账号，填写微信号并确认。应用重新检查后才启用读取，人工核验不代表应用已自动识别登录账号。
2. 在“随访 → 聊天随访”选择患者，填写会话名称、联系人称呼及本人/家属关系。
3. 在微信打开对应聊天，读取窗口预览。应用先尝试定位唯一匹配的标题；核对建议区域，识别失败时手动框选。选择消息区域，避开左侧会话列表、输入框及无关区域。也可用百分比数值调整。
4. 核实账号与会话身份后关联。同步时校验标题与窗口比例，遇到歧义、窗口变化或识别失败停止。
5. 查看本次原文与裁剪证据，人工填写草稿或单独授权 AI 整理，再确认联系时间与患者归属后归档。

微信读取的是当前可见区域，不是完整历史。无法可靠判断的发言人和发送时间明确标为待核验；相同可见文本重复读取会跳过，相邻画面仅去掉可靠的连续重叠；无法确定连续性时保留原文并提示可能遗漏或重复，不能据此推定没有其他未读消息。窗口布局、账号或会话备注改变后应解除旧关联并重新核验。当前适配不支持自动翻阅全部历史、语音转写、发送消息或 Windows 客户端。

微信定时读取在明确截止时间内只读取选定的一个已校准会话，会显示微信窗口但不搜索或切换联系人；发生读取错误后暂停自动运行。企业微信仍按已关联范围增量同步。最多配置未来 24 小时，工作台退出后停止。默认仅生成原文草稿。可独立勾选并授权自动调用当前模型整理新增草稿；更换模型或服务地址后停止自动整理，需重新授权。每轮最多整理 3 份，失败后由用户手动重试。自动整理不会完成随访或发送消息。

## 企业微信

先在独立部署环境配置会话存档采集器，见[采集器说明](../integrations/wecom-archive/README.md)。客户联系接口、成员确认发送任务与会话存档是不同功能。

展开“管理员配置”，填写企业 ID、采集器地址和访问密钥，点击“验证并连接企业服务”。验证失败只保存配置，不启用连接；修正后可重试。连接成功后，医生可直接进入患者会话关联。管理员配置是操作分工入口，不是多用户权限系统。测试成功只说明采集器和存档读取可用，具体聊天范围仍受官方存档权限影响。

在患者下读取可关联会话并核实关系。新增关联重新扫描当前可用存档；重复消息不重复生成草稿。分页中途失败保留已成功提交的页，后续从检查点继续。更换企业或采集器地址时旧绑定失效。

## 本人、家属与多人会话

每个关联都保存患者与联系人关系。企微已核验的发送者可标为本人或家属转述，其他参与者保留待核验。微信截屏原文不擅自推断发送者。

企微群聊或同一会话同时关联多个患者时，新增消息进入“待分配消息”，需明确选择属于当前患者的内容后再生成草稿。解除关联停止后续采集，已有草稿及归档证据保留；删除患者时清理其关联和不再被其他患者引用的来源数据。

## 草稿与归档

AI 整理需要单独确认向当前模型发送本次原文。模型只接收固定原文快照，不调用聊天中的指令或发送工具。模型生成期间如果医生编辑了草稿，晚到的模型结果不会覆盖人工修改。

归档须核对内容、真实联系时间和患者归属。重复提交不会重复登记随访。撤回消息会标记来源变化，已有归档记录不被悄悄重写。采集证据保存在本机业务数据库中，原文和截图随患者数据一同管理。

## Mac 微信读取与文件导入

微信窗口读取只处理已经打开并校准的会话。标题不匹配时提示手动打开，不会自动搜索、点击同名结果或输入消息。每次读取对标题及消息区域进行两次视觉核验；画面改变、窗口移动、登录或安全验证提示都会中止。辅助功能树不含聊天控件时使用本地 Apple Vision OCR，权限检查通过不等于登录身份已验证。

定时读取必须选择一个已校准会话和截止时间。会话不匹配或读取失败后停止，需要手动恢复。旧的多会话轮转计划不再执行。

聊天随访提供「导入微信聊天记录」：选择微信主动导出的 ZIP 或 TXT，在本机预览原文，核对当前患者、会话与本人/家属关系后生成待复核草稿。此入口不要求启用微信桌面连接或授权录屏；它尚不是 macOS 分享菜单扩展。ZIP 必须只有一份可用 TXT，最大文件 4 MB、500 个文件、文本 14000 字；附件仅记录文件名，不分析媒体。文本支持 UTF-8 和带 BOM 的 UTF-16LE。来源保留文件摘要和导入文本；不会凭文件名自动证明联系人身份，不自动提取发送人或时间。

相同患者、会话、关系及联系人下的相同导入文本去重；部分重叠的不同导出批次仍需人工复核。导入文件不授权桌面读取、定时采集或自动模型调用。调用模型整理仍需对每份草稿单独授权。
