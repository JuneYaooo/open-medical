# 通用 Agent 发布门槛

先具备可独立使用的通用 Agent，再叠加领域能力。领域模块只能增加专业约束和工具，不能替通用执行能力兜底。新增医疗功能不能作为下列通用门槛的替代验收。

| 门槛 | 必须验证的结果 | 当前证据及剩余限制 |
| --- | --- | --- |
| G0 | 通用服务独立启动，医疗功能和权限边界不回归 | 独立 CLI/HTTP 服务、无患者表测试及医疗回归；完整 Docker 测试结果记录在能力文档 |
| G1 | 读文件→复现失败→修复→验证→交付/本地提交 | 真实 DeepSeek 修复验收；自动写入及 Git 各自授权；远端 PR 账号流程不在当前验收范围 |
| G2 | 追加要求、自动压缩、历史回查、同任务恢复、后台执行 | 持久化工具意图和结果；恢复前校验模型/权限/预算；真实模型 continuity 用例与强杀回归；48小时 soak 必须实际结束后才算长时通过 |
| G3 | 可写团队、依赖/冲突/取消、Skills、Plugins、MCP、OAuth 生命周期 | 单层团队与本项目插件格式；本地 MCP/OAuth 协议检查；递归/跨模型团队、外部供应商兼容和 marketplace 仍未完成 |
| G4 | 文档/图片/网页/结构化数据可输入、处理、检查和下载 | 基本 Office/PDF/ZIP/JSON/CSV 及成果回读；复杂排版、通用桌面控制、音视频、多适配器视觉仍未完成 |
| G5 | 真实模型任务集、多平台、长负载及故障恢复 | 按模型和源码指纹记录每次任务成功率；Mac Docker 回归不能替代 Windows 实机或48小时结果；没有普遍可靠性保证 |
| G6 | 以上发布要求达到后，再扩展医疗/科研/企业域 | 当前仍有 G3–G5 缺口，不把版本号、工具数量或一次测试通过当作完整发布批准 |

真实任务验收入口：`npm run verify:agent -- --repeat=3`。每次报告记录模型、源码指纹、任务、结果、token、轮次和耗时；使用合成资料，但模型请求必须真实。跨供应商比较需要分别运行，不能沿用另一模型的成功率。没有价格配置时只报告 token，不编造货币成本。

长时验收入口：`npm run verify:soak -- --background --hours=48 --image=open-medical-runtime:0.8-full`。报告的 `durationTargetMet` 必须为 true；短迭代验收、运行中、电脑休眠/关机或中途失败都不能声称已经达到48小时。
