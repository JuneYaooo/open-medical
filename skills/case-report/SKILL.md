# 个案报告写作

只使用当前会话材料（可引用病例库条目并注明）。

## 工作流
1. **脱敏先行**：姓名→缩写或"患者"，删除住院号/身份证/电话/精确 dates 改为相对时间；去标识后再写作。
2. 用 `extract_clinical_timeline` 与 `extract_observations` 提取事实，保留出处。
3. 事件取舍口诀：省略这个事件，会不会影响对病程的理解？保留诊断节点、治疗节点、关键评估（有重要发现的影像/病理/标志物）、决策节点；术前常规检查并入当日主事件。
4. 按 CARE 结构输出：标题建议 → 摘要（背景/病例要点/结论）→ 引言 → 病例资料（主诉/现病史/查体/辅助检查/诊疗经过）→ 讨论（标注"可结合文献检索补充证据"，引用需真实可查）→ 结论 → 患者知情同意提示。
5. 结尾列"发表前核对清单"：目标期刊格式、知情同意书、患者已脱敏复查。

## 纪律
- 限定词保留（疑似/考虑）；讨论部分区分"本例观察"与"文献已知"。
- 不引用无法核实的文献；如需文献支持，用 `literature_search` 检索真实条目。
