# 出院小结草稿

只使用当前会话材料和工具返回结果。

## 工作流
1. 用 `extract_clinical_timeline` 提取住院关键节点（入院、确诊、手术/转科、病情变化、出院）。
2. 用 `extract_observations` 摘录关键检验，保留单位和原文行号。
3. 整理出院带药清单，调用 `medication_safety_check` 核查（含 populations 参数如有特殊人群信息）。
4. 按结构输出：入院日期/出院日期（缺失标「待补充」）、入院诊断、出院诊断、住院经过摘要、出院时情况、出院带药（药名/剂量/频次）、出院注意事项、随访计划（复诊时间、复查项目）。
5. 成稿后调用 `make_review_checklist`，标题用「出院小结草稿 ·（患者/材料名）」，把小结各节要点（含每处「待补充」）作为 items 落成待复核产物——小结不能只留在回复里，医生要能在产物面板核对与归档。

## 纪律
- 保留"疑似""考虑""建议复查"等限定词，不把影像或病理描述升级为确定诊断。
- 病程事件判断口诀：省略这个事件，会不会影响对病程的理解？常规检查（术前血常规、心电图）并入当日主事件，不单列。
- 医院名称不得保留"本院""我院"，替换为材料中的具体名称或省略。
- 全文为待医生核对签署的草稿；出院诊断必须有材料依据，不得新增。
