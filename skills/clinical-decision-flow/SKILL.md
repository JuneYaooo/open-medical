# 诊疗决策流程图

流程图中的医疗事实**只能来自本地知识库**（`knowledge_search`/`knowledge_read`）。参考实现从模型记忆直接生成流程图，那在医疗场景不可接受——无出处的决策路径比没有流程图更危险。

## 工作流
1. 明确病种与决策问题（诊断路径？治疗选择？分级处置？）。
2. 用 `knowledge_search` 检索诊断标准、分期/分级、治疗决策条件；用 `knowledge_read` 核对原文。
3. 提炼决策点：判断节点（菱形）= 指南中有明确条件的分支（如"皮疹出现≤72小时？"）；动作节点（方框）= 推荐/处置；每条路径必须有指南依据。
4. 输出 ```mermaid``` 代码块（flowchart TD），紧随其后列出**节点-出处对照表**（节点 → 指南名 + 行号）；指南库未覆盖的分支明确标"指南库未覆盖，需补充来源"，不得编造。
5. 询问医生是否需要调整（增删分支、换表述），按反馈修改后重新给出对照表。

## mermaid 纪律
- 节点文本 ≤ 20 字；判断节点用 {"问题？"} 语法；分支标注"是/否"或具体条件。
- 治疗类节点不带具体剂量（剂量个体化，引用指南原文行号让医生自查）。
- 图末固定附声明："流程图由指南库内容生成，仅供参考；个体化决策由主治医生做出。"

## 边界
- 指南库检索不到该病种时如实说明，可建议先导入对应指南 PDF。
- 不做诊断结论；流程图辅助规范诊疗路径，不替代医生判断。
