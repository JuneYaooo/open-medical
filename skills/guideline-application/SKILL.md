# 指南应用

指南事实只来自 `guideline_search`/`guideline_read`（本地指南库）；库中没有的不得凭记忆编造条文。

## 工作流
1. 把临床问题拆成可检索的关键词组合（PICO 方向），调用 `guideline_search`；机构/年份过滤优先用医生档案中的常用指南来源。
2. 引用必须带**指南名 + 行号**（工具返回的 startLine/matches）；引用前可用 `guideline_read` 核对原文上下文，防止断章取义。
3. 区分并保留原文的推荐等级与证据级别表述；不同指南意见冲突时并列展示，不裁决。
4. 输出：问题 → 指南推荐（带出处）→ 与该患者的差异点（列出医生需权衡的患者特征）→ 声明"推荐意见供参考，个体化决策由主治医生做出"。

## 纪律
- 指南更新有版本：引用时注明指南名称与年份。
- 本地库未收录的指南主题如实说"指南库未覆盖"，可建议用 `literature_search` 找证据，不得混入记忆中的"指南说法"。

## 建立知识库（用户要求时）
1. 用户上传指南文件：读取全文后向用户复述将入库的标题与来源，确认后调用 `guideline_ingest` 入库（自动分块并向量化）。
2. 用户要求联网找指南：用 `literature_search` 或 web 工具获取候选，展示标题/机构/年份与摘要供用户挑选；用户确认后再获取全文并 `guideline_ingest` 入库。
3. 入库完成后告知：已自动索引（语义 + 全文双路检索），之后回答医学问题会先检索知识库。
4. 入库失败（如文本过短）如实说明原因，不要降低校验绕过。

## 向量索引维护
- 知识库向量绑定嵌入模型（默认 bge-m3，可经 MEDICAL_EMBEDDING_MODEL 环境变量更换为 qwen3-embedding 等）；更换模型后旧向量自动标记为陈旧，检索仍可用（全文匹配兜底）并提示重建。
- 重建调用 REST `POST /api/guidelines/reindex`（或在指南库界面点「重建向量索引」），完成后告知医生新的模型与块数。
- 用户询问嵌入方案时：本地免费推荐 qwen3-embedding（质量最强）与 bge-m3（均衡多语言），均为 Ollama 可拉取；nomic-embed-text 偏英文不推荐用于中文医疗。
