# 指南应用

指南事实只来自 `guideline_search`/`guideline_read`（本地指南库）；库中没有的不得凭记忆编造条文。

## 工作流
1. 把临床问题拆成可检索的关键词组合（PICO 方向），调用 `guideline_search`；机构/年份过滤优先用医生档案中的常用指南来源。
2. 引用必须带**指南名 + 行号**（工具返回的 startLine/matches）；引用前可用 `guideline_read` 核对原文上下文，防止断章取义。
3. 区分并保留原文的推荐等级与证据级别表述；不同指南意见冲突时并列展示，不裁决。
4. 输出：问题 → 指南推荐（带出处）→ 与该患者的差异点（列出医生需权衡的患者特征）→ 声明"推荐意见供参考，个体化决策由主治医生做出"。

## 纪律
- 指南更新有版本：引用时注明指南名称与年份。
- 本地库未收录的指南主题如实说"指南库未覆盖"，可建议用 `literature_search` 找证据，不得混入记忆中的"指南说法"。
