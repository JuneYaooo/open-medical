# 相似病例检索

先用 `read_patient_brief` 读取当前患者（如已关联），仅用当前患者材料构建指纹。本地用 `similar_case_search` 检索（包含其他未归档患者，自动排除当前患者）；网上用 `online_case_search` 检索 PubMed/Europe PMC 病例报告。检索前先把当前病例整理为结构化指纹：专业方向、年龄段、性别（如相关）、主要表现、病程、关键阳性发现、关键阴性发现、检验/影像/病理、疑似或确诊诊断、干预、反应与结局、罕见鉴别特征。

## 工作流
1. 用 `similar_case_search` 检索，传入 caseText（指纹拼接）与 diagnosis（主轴加权）。
2. 将指纹提炼为脱敏英文医学关键词，调用 `online_case_search`。不能发送姓名、电话、编号、精确就诊日期。用 `literature_fetch` 或 `web_fetch` 核对候选原文；需要中文补充时用 web_search 检索中华医学会病例库等，明确未覆盖、访问失败与缓存来源。按 DOI/PMID 去重，重复报道不算独立患者。结果分别列「本地患者/病例」与「网上文献」，不能把检索分数写成临床相似概率。
3. 对每个候选执行**主轴核验门禁**：先确认候选与当前患者是同一主要疾病或综合征。症状、检验、治疗、年龄、结局的相似**不能弥补主轴不符**——未过门禁的候选只能称"文献线索"，不能称"相似病例"。
3. 核对匹配理由中的术语命中：文本缺失是「未知」，不是「不匹配」；只把明确写出的冲突当作反面证据。
4. 按病例特异的 4–7 个维度评分（权重合计 100，如：罕见鉴别特征 20 / 主要表现与病程 20 / 关键检验影像病理 20 / 确诊或最接近鉴别诊断 15 / 年龄性别共病 10 / 干预与反应 10 / 结局 5），每维 0–5 分；无证据的维度从分母剔除并单独报告覆盖率。
5. 呈现时区分四种独立性声明：检索置信度 ≠ 临床相似度 ≠ 来源质量 ≠ 引用支持。

## 边界
- 相似性仅用于文献回顾和提出假设，不能确定当前患者的诊断、因果、治疗适用性或预后。
- 文献候选未做患者级核验前，不计为独立患者病例（可能重复报道同一患者）。
- 不编造候选文献中不存在的特征。
