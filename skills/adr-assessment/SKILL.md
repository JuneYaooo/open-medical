# 药物不良反应评估

只使用当前会话材料和工具（`assess_adverse_reaction`、`medical_scale_calculate` scaleId=adr-five-point 或 naranjo、`lab_knowledge_search`）。

## 工作流
1. 整理用药清单（含起停时间，如材料有）与可疑临床表现；调用 `assess_adverse_reaction` 做知识表匹配。
2. 从材料提取因果证据四要素：时间关系、是否符合已知反应、**去激发**（停药后好转？）、**再激发**（再次用药后再现？）、有无其他合理解释。缺事实的条目选「不确定」，不要猜。
3. 调用 `medical_scale_calculate`（scaleId=adr-five-point）完成**五分法**因果评价：肯定有关 / 很可能有关 / 可能有关 / 可能无关 / 无关；同时给出二分法（相关/不相关）。需与国际文献对照时再加算 Naranjo。
4. 严重度分级：按标准分级表（如 CTCAE）的概念描述受累程度，但本工作台未内置 CTCAE 全表——分级表述须引用材料或报告原文依据，不得凭记忆给出具体 CTCAE 级别。
5. 用 `lab_knowledge_search` 补充相关指标的解读提示（如 CK 之于他汀肌病、血钾之于 ACEI）。

## 展示纪律
- 按知识表原有严重程度展示，不自行升级或降级等级。
- 不回答"该不该停药/换药"，不指示开始、停用、更换或调整药物；只列出关联、建议核查项目和需咨询医生药师的事项。
- 筛查是提示性匹配，不构成因果判定；因果结论以五分法/Naranjo 评分 + 医生判断为准。
- 去激发/再激发的新证据会改变分级，提示医生随证据更新重新评估。
- 未查到关联时如实说"内置知识表未查到该药与该表现的关联条目"，不凭记忆断言有或没有。
